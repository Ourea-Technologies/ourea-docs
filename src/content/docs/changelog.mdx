## Versioning

- **v1 changes only additively.** New fields, parameters, routes, error codes
  and enum values can appear within v1. Ignore unknown fields and treat
  unknown enum values as "other"; treat an unknown error code by its HTTP
  status. Breaking changes go to `/api/v2`.
- `info.version` in the [OpenAPI spec](/openapi/v1/openapi.yaml) is the
  contract version: 1.0.0 at the v1 lock.
- The official SDKs are versioned independently of the API (0.x until each
  passes its pre-1.0 review) and each README states the contract it targets.
- The [Cap'n Proto schema](/capnp/#versioning) is append-only within v1.
- Value precision may get finer within v1, never coarser.

## Deprecation policy

A deprecated field, parameter or route is **announced at least six months
ahead**. While it is deprecated, responses that use it carry:

- `Deprecation`,
- `Sunset` (when it stops working),
- `Link` with `rel="deprecation"` pointing at the notice.

The SDKs surface these once per operation per process, through the
language's warning channel (Python `warnings`, a logger elsewhere), with the
`Link` URL. Nothing in v1 is deprecated today.
