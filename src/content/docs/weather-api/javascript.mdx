Every Ourea response is JSON over HTTPS, so `fetch` is all you need, in the browser, Node.js, Deno or Bun. [Ourea](https://oureawx.com) serves ensemble forecasts for the
contiguous United States: each value is a distribution (p10 to p90), and the
chance of an event is computed on the server from every ensemble member.
Named locations need **no signup and no API key**; forecasts at arbitrary
coordinates need Pro.

## Your first call, no SDK

This uses only `fetch`. In a browser module, drop the `process.env` line.

<HttpExample lang="javascript" />

It prints each hour's temperature range and the chance of at least 6 in of
snow at Mt. Hood Meadows in the next 24 hours. The URL is in canonical form
(parameters in alphabetical order, literal `:` in `prob`), so anonymous calls
share the edge cache: see [Caching and ETags](/features/caching/).

## Notes

In the browser, call Ourea anonymously or from your own backend: never ship an API key in client-side code. The API answers cross-origin `fetch` requests (CORS). For Node.js specifics, see [Weather API for Node.js](/weather-api/nodejs/).
