`ensembleweather` is the official R package: forecasts arrive as data frames, ready for the tidyverse or base R. [Ourea](https://oureawx.com) serves ensemble forecasts for the
contiguous United States: each value is a distribution (p10 to p90), and the
chance of an event is computed on the server from every ensemble member.
Named locations need **no signup and no API key**; forecasts at arbitrary
coordinates need Pro.

## Notes

A probability the server could not answer is `NA`, never 0. The package
reference, with every function and its arguments, is the
[pkgdown site](https://ourea-technologies.github.io/ensemble-weather-r/).

- [Getting started](/getting-started/?lang=r) shows every example on the
