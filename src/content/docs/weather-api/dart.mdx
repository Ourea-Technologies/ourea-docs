`ensemble_weather` is the official Dart SDK: one package for Flutter apps on Android, iOS, desktop and web, and for the Dart VM. [Ourea](https://oureawx.com) serves ensemble forecasts for the
contiguous United States: each value is a distribution (p10 to p90), and the
chance of an event is computed on the server from every ensemble member.
Named locations need **no signup and no API key**; forecasts at arbitrary
coordinates need Pro.

## Install

<LanguageNotes sdk="dart" />

In a Flutter app, `flutter pub add ensemble_weather` does the same.

<Aside type="note">
The SDK's first release is 0.1.0. Until it is published to pub.dev, the curl
tab of any example on this site shows the exact request it sends.
</Aside>

## Notes

Never embed an API key in an app binary: call anonymously or through your own backend. A `null` probability means the served series does not reach the window's end; it is never 0.
