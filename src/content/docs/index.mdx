## What Ourea is

Ourea serves forecasts for the contiguous United States, blended from up to five
weather-model ensembles per forecast hour: ECMWF AIFS-ENS and IFS-ENS, and NOAA
AIGEFS, GEFS and RRFS. It is a calibrated, post-processed blend of physics and AI
ensembles. Every hour's full distribution is served beside its headline numbers.

- **Probability first.** Each forecast value is a distribution (`mean`, `p10`,
  `p25`, `p50`, `p75`, `p90`, and `min`/`max` where served), not one number.
  Ask for the chance of an event with `prob=` and the server computes it from
  every ensemble member.
- **Server-side statistics.** Probabilities, window totals and ranges are all
  computed on the server from the full ensemble, so every client gets the same
  answer and nobody adds up quantiles by hand.
- **Named places and coordinates.** Forecasts for catalog locations (ski areas,
  passes, trailheads, towns, airports) work without a key. Forecasts at any
  point need Pro.
